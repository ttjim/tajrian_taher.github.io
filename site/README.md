# Portfolio

Static site for GitHub Pages.

## Publish
1. Create a repo named `YOUR_USERNAME.github.io` and upload these files.
2. Settings > Pages > deploy from the `main` branch, root folder.
3. Visit https://YOUR_USERNAME.github.io

## Add your photos (put them in /images)
- `portrait.jpg`
- For each project: `<id>-1.jpg` (large), `<id>-2.jpg`, `<id>-3.jpg`
- Ids: drone-perching, neural-drone, ring-counter, cartpole, transmission, second-life-battery, webwork-notifier, lubbock-today

Empty slots show a striped placeholder until the file exists.
Also replace YOUR_EMAIL, YOUR_USERNAME and YOUR_PROFILE in index.html.
